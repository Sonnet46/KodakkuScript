# KodakkuAssist 脚本项目

本项目维护 KodakkuAssist（可达鸭）单文件 C# 脚本。脚本由插件在游戏内动态编译；仓库中的工程文件仅用于 IDE 智能感知和编译期校验。

## 目录

```text
Kodakku/
├── Scripts/                       # 按版本或资料片组织的脚本
├── ScriptParser/                  # 生成在线库索引
├── KodakkuAssistScripts.csproj    # 脚本编译校验
├── OnlineRepo.json                # 在线库清单
└── update.bat                     # 本地生成命令
```

## 开发流程

1. 在 `Scripts/` 下新增或修改 `.cs` 脚本。
2. 确认 `[ScriptType]` 中的 `guid` 唯一且发布后不变。
3. 更新版本号，并在 `[ScriptType]` 中填写当前版本的 `updateInfo`；该字段会写入 `OnlineRepo.json` 的 `UpdateInfo`。
4. 在脚本类内维护 `UpdateHistory` 常量，按版本倒序记录完整更新历史。
5. 确认 `territorys`、Action/Status/TargetIcon 等 ID 来自当前版本的事件查看器或日志。
6. 使用脚本前缀命名绘图，并只清理自己的前缀。
7. 运行 `update.bat` 更新 `OnlineRepo.json`。
8. 使用 `dotnet build KodakkuAssistScripts.csproj` 做编译校验。
```bash
dotnet build KodakkuAssistScripts.csproj
```

元数据示例：

```csharp
[ScriptType(
    guid: "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
    name: "示例脚本",
    territorys: [1234],
    version: "0.0.0.2",
    author: "作者",
    updateInfo: "修正第二阶段点名触发逻辑并补充指路")]
public class ExampleScript
{
    private const string UpdateHistory = """
        更新历史：
        - v0.0.0.2：修正第二阶段点名触发逻辑并补充指路。
        - v0.0.0.1：初次提交。
        """;
}
```
## 版本与兼容性

当前校验项目按 KodakkuAssist `0.5.1.54`、Dalamud CN SDK 15 和 .NET 10 配置。若本机插件版本不同，应同步修改 `KodakkuAssistScripts.csproj` 和本文档。

## 重要约定

- 不使用 `RemoveDraw(".*")` 清理全局绘图。
- 延迟任务需要考虑切图、重置和重复触发。
- 共享状态在事件并发执行时使用锁或并发集合保护。
- 仅完成静态编译时，不将脚本描述为已实战验证。
